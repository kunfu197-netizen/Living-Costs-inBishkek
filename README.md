# BaaKarta: администратор панели

## Талаптар

- PHP 8.1+ (PDO MySQL, Fileinfo жана JSON кеңейтүүлөрү менен)
- MySQL 8.0+ же MariaDB 10.6+
- Өндүрүш серверинде HTTPS

`index.html` жана `map.html` мурдагыдай эле статикалык бойдон иштейт. Админге өзгөртүлгөн маалыматтар `/api.php` аркылуу берилет; пикирлер адегенде текшерүү кезегине түшөт.

## Орнотуу

1. MySQL'де өзүнчө маалымат базасын жана ага гана уруксат берилген колдонуучуну түзүңүз. `schema.sql` файлын ошол маалымат базасында аткарыңыз.
2. Веб-сервердин чөйрөсүнө төмөнкү өзгөрмөлөрдү кошуңуз:
   - `BAAKARTA_DSN=mysql:host=127.0.0.1;dbname=baakarta;charset=utf8mb4`
   - `BAAKARTA_DB_USER` жана `BAAKARTA_DB_PASSWORD`
   - Керек болсо `BAAKARTA_UPLOAD_DIR` аркылуу коомдук веб-тамырдан тышкаркы жазылуучу сүрөт папкасын көрсөтүңүз.
   - Өндүрүштө `BAAKARTA_ALLOW_HTTP` коюлбай турганын текшериңиз: админ жана API HTTPS'ти милдеттүү талап кылат. Локалдык иштеп чыгууда гана `BAAKARTA_ALLOW_HTTP=1` колдонсо болот.
3. Сервердин командалык сап терминалында администраторду түзүңүз. Сырсөз интерактивдүү түрдө суралат:

   ```text
   php create_admin.php <колдонуучу_аты>
   ```

   Кеминде 12 белгиден турган уникалдуу сырсөз тандаңыз. PHP аны пароль хэш алгоритми менен сактайт.
4. Папканы PHP иштете алган веб-хостингге жайгаштырыңыз. `admin.php`, `api.php` жана сүрөттөр үчүн HTTPS иштетип, `includes/` жана `schema.sql` файлдарына коомдук HTTP кирүүнү веб-сервер деңгээлинде жабыңыз.
5. `/admin.php` дарегине өтүп кириңиз. Сайттын картасы маалыматтарды `/api.php` аркылуу алат.

`BAAKARTA_UPLOAD_DIR` үчүн веб-тамырдан тышкары жайгашкан, веб-процесске гана жазууга уруксат берилген папканы колдонуңуз. `image.php` текшерилген сүрөттөрдү гана берет. Apache үчүн `includes/.htaccess` жана `uploads/.htaccess` коргоону берет. Nginx колдонулса, `includes/`, `uploads/`, `schema.sql` жана `create_admin.php` үчүн `deny all` эрежелерин конфигурациялаңыз.

### Маалыматтарды башкаруу

Админ панелинен дүкөн, мейманкана жана базар түзүп/өзгөртүп/жашырып же шектүү деп белгилей аласыз. Товарлар ар бир дүкөнгө же базарга байланып, сом менен сакталат. Сүрөттөр 5 МБга чейин; JPG, PNG жана WebP кабыл алынат. Кошумча маалымат JSON объектиси катары киргизилет:

- Дүкөн: `{"avg":800,"hours":"08:00–22:00","items":"Азык-түлүк","delivery":"Бар","parking":"Жок","tag":"Супермаркет","stars":4.2}`
- Мейманкана: `{"min":2000,"max":4000,"rooms":65,"pool":"Жок","wifi":"Бар","breakfast":"Кошулган","tag":"3★","stars":3.9}`
- Базар: `{"veg":"50–300","meat":"400–700","clothes":"150–1500","hours":"07:00–19:00","specialty":"Жашылча жана жемиш","tag":"Азык-түлүк","stars":4.1}`

Админ панелинен кошулган жана жаңыртылган жайлар сайттын картасына серверден жүктөлөт. Админ сүрөт жүктөгөндө HTML/JavaScript браузерде гана сакталган маалыматтарга таасир бербейт. Картанын район баалары үчүн мурдагы локалдык сактоо механизмин бул панель сервердик базага көчүрбөйт.

Баштапкы картадагы мисал дүкөндөр/мейманканалар/базарлар `map.js` ичинде статикалык демонстрация маалымат катары калат жана базага автоматтык импорттолбойт. Админ панелиндеги өзгөртүүлөр маалымат базасына кошулган жайларга тиешелүү; эски демонстрация карточкаларын админден өзгөртүү үчүн аларды базага өзүнчө көчүрүү керек.
